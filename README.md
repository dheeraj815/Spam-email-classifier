# 📧 Spam Email Classifier

An NLP-based spam detection system that classifies emails as Spam or Not Spam
using machine learning and text analysis.


## ✨ Features

- 📩 Real-time spam detection
- 📊 Confidence percentage shown
- 🧹 Text preprocessing — stopwords, stemming, TF-IDF
- 📈 Model accuracy and performance metrics
- ⚡ Instant results


## 🧠 Tech Stack

- Python
- scikit-learn
- NLTK
- Pandas
- NumPy
- Streamlit


## 📊 Models Used

- Naive Bayes
- Support Vector Machine
- Logistic Regression
- TF-IDF Vectorizer


## ▶️ Run Locally

git clone https://github.com/dheeraj815/Spam-email-classifier.git
cd Spam-email-classifier
pip install -r requirements.txt
streamlit run app.py
