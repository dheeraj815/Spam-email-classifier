# AI-Powered Spam Email & SMS Detection System

Intelligent spam detection and text classification platform using Natural Language Processing (NLP) and Naive Bayes / Ensemble classification.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.32%2B-FF4B4B?logo=streamlit&logoColor=white)](https://streamlit.io)
[![Author](https://img.shields.io/badge/Author-Dheeraj%20Muley-black?logo=github)](https://github.com/dheeraj815)

## Key Features
- **Real-Time Classification**: Instant Ham vs Spam classification with probability confidence scoring
- **NLP Text Pipeline**: Custom stopword removal, punctuation stripping, and TF-IDF vectorization
- **Keyword & Pattern Insights**: Highlights suspicious trigger words and phishing phrases
- **Message History & Export**: Session-based query logging with CSV export capabilities
- **Executive UI**: Clean, responsive Streamlit dashboard with probability distribution gauges
